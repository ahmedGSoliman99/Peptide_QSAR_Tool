# Deposited example

`LEAK.pdb` is the exact target structure used for the validated DNA-generation run. The structure encodes the 13-residue sequence `MDAKDKLKEKAKE`.

`LEAK_test_DNA_output.log` is deposited here as a compact execution record of the validated run that produced the 26-nt sequence `CTTCTGGTTCTTGCTTGTCTGCCTCC`.

These files document software execution. They do not by themselves establish biological affinity or specificity.
